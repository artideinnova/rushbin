# Security

## Reporting a vulnerability

Please report it privately, never in a public issue:

- on GitHub: this repository, **Security**, **Report a vulnerability** (a private report only Artide sees), or
- by email to hello@artide.studio, with "security" in the subject.

Say what is affected (the Mac or Windows app, the team site, a self-hosted site), how to reproduce it, and what an
attacker gains. We answer within 3 working days, keep you informed, and credit you when the fix is published, if you
want.

## What is in scope

The apps, the team site and the deployment files in this repository, including a self-hosted site set up as
`docs/self-host.md` says. Artide's own site, rushbin.io, too: please do not access data that is not yours, do not
degrade the service, and stop at the proof that the problem exists.

## Supported versions

The latest release of the apps and the latest commit of the team site. A self-hosted site gets fixes by updating
(`docs/self-host.md`, Update).
